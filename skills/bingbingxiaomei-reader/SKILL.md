# 冰冰小美知识库阅读工作流

## 核心原则

1. **一次只展示一条帖子原文**，不要批量展示、不要提前总结
2. **必须等待主人明确说"下一条""继续""整理，下一条"等指令**，绝不能擅自推进
3. **中间的问答、讨论、解释，全部记录到当天笔记**，不只是最终结论
4. **解读要逐层拆解**，不跳过任何逻辑环节
5. 主人提出的观点（如"在危机中看到机"）也要记录到笔记
6. **不跳过任何帖子**——哪怕只有一个字（如"哼"），也要展示

## 帖子状态追踪

每条帖子都用以下状态标记，记录在 `progress.json` 的 `dates.{date}.posts` 中：

### 状态定义

| 状态 | 含义 | 触发条件 |
|------|------|----------|
| `shown` | 已展示给主人 | 帖子原文已输出 |
| `discussed` | 有过讨论/解读 | 主人参与讨论，或给出了逐层拆解 |
| `noted` | 已写入阅读笔记 | 内容和讨论已写入当天笔记文件 |
| `waitlisted` | 该帖概念已加待学清单 | 主人说"记录一条"，独立标记，可与 noted 共存 |

### 状态流转

```
shown → discussed → noted
              ↘ waitlisted（可选附加标记，不参与主流转）
```

- **每一步都必须立即更新 progress.json**，不能等会话结束时才补
- 主人说"下一条"时，当前帖子至少应处于 `shown` 状态
- 讨论过的帖子标记 `discussed: true`
- 写入笔记后状态改为 `noted`

## 阅读流程

### 启动时（双重校验）

1. 读取 `progress.json`
2. 找到所有 `shown` 但非 `noted` 的帖子 → 提示主人"上次有未整理完的帖子"
3. 找到最新一条 `noted` 的帖子作为起点
4. **交叉校验**：读当天的阅读笔记（`输出/YYYY-MM-DD-帖子阅读笔记.md`），确认笔记最后一条是否与 progress.json 一致
5. 以**笔记为准**，从笔记最后一条的下一帖开始展示
6. 如果没有进度，从最新一批帖子中最早的开始

### 每条帖子（强制步骤）

1. 展示原帖内容（带序号 + 日期时间标签，格式：`**帖子 #N** — YYYY-MM-DD HH:mm`）
2. 如果帖子有实质内容，给出逐层拆解；如果内容极短（如"哼"），简单标注即可
3. **立即更新 progress.json**：该帖状态至少设为 `shown`
4. **等待主人明确指令**，可能的指令：
   - 主人有讨论/提问 → 深入讨论，更新状态为 `discussed`，讨论完毕后等"整理"指令
   - 主人说"下一条" → 如果当前帖子只有 `shown` 就停在 `shown`；如果有讨论就把 `discussed` 设为 true，然后读下一条
   - 主人说"整理" → 将当天所有 `shown`/`discussed` 帖子写入笔记，状态改为 `noted`
   - 主人说"整理，下一条" → 先整理再展示下一条
   - 主人说"记录一条XXX" → 加入待学清单，该帖加 `waitlisted: true`

### 整理笔记

- 同一天的帖子整理到一个 md 文件：`输出/YYYY-MM-DD-帖子阅读笔记.md`
- **每条帖子的笔记内容必须完整**，包括：
  - 原文引用
  - 逐层拆解
  - 讨论中的关键洞察
  - 主人提出的观点
- 整理完成后，将对应帖子的状态改为 `noted`
- 双联：原帖 frontmatter 加 `笔记: "[[笔记文件名]]"`

### 更新进度（强制，每次操作后立即执行）

每完成一个操作（展示/讨论/整理），**立即**更新 `progress.json` 中对应帖子的状态。

```json
{
  "last_read_at": "2026-05-18T00:00:00",
  "dates": {
    "2026-05-08": {
      "posts": {
        "帖子_209806278_2026-05-08_14-08": { "status": "noted" },
        "帖子_104149988_2026-05-08_14-17": { "status": "shown", "discussed": true },
        "帖子_492237411_2026-05-08_14-55": { "status": "shown" }
      }
    }
  }
}
```

## 帖子文件命名规则

`帖子_{hash}_{YYYY-MM-DD}_{HH-mm}.md`

按日期+时间排序即可得到阅读顺序。

## 笔记模板

每条被解读的帖子，按以下结构记录：

```markdown
## N. 标题（HH:mm）

原帖：[[帖子文件名]]

> 冰美原文引用

**逐层拆解：**
每一层的逻辑分析

**讨论中的关键洞察：**
主人的观点和讨论要点
```
